# 彩灯骨架扎制与透光预览系统

面向自贡彩灯工艺的浏览器端设计工具：钢丝骨架扎制、绸布蒙皮、LED 布灯、透光物理烘焙、夜景预览与下料单，数据全部存于浏览器 IndexedDB，不上传服务器。

## 启动

```bash
pnpm install
pnpm dev        # 开发，默认 http://localhost:5180
pnpm build      # 类型检查 + 生产构建
pnpm test:optics  # 透光手算口径校验（11 项）
pnpm test:perf    # 几万面烘焙性能测试
```

首次打开会自动播种一个灯会项目和三个测试灯组：腾龙（3 段）、盛世荷花、仕女人物。灯组列表页可随时重新生成。

## 六个页面

1. **灯组列表**：按灯会项目管理灯组；卡片显示分段数、灯具数、总功率、外包尺寸，超运输限界标红
2. **骨架编辑**：地面加节点、两点连杆、节点三轴拖拽；截面放样按环形截面快速生成龙身类管笼（Catmull-Rom 样条 + 平行运输标架）；左下角实时显示钢丝总长、自重、简支梁挠度与运输尺寸
3. **蒙布**：矩形蒙布生成、布色/厚度/透光率/散射系数、余弦型布面下垂、顶点级手绘颜料（颜料区 τ 衰减）；右上角手算校验卡逐项列出 E、τ_eff、Eout
4. **灯光布置**：点光源与灯带（按灯珠间距离散）、功率/色温/发光效率可调；灯具数、发光珠数、总功率、灯带米数实时统计；烘焙后给出暗区/光斑自动灯位建议并在场景标记
5. **夜景预览**：压暗环境的夜景场地、Reflector 实时水面倒影、环绕观察与 1.6m 眼高地面行走（W/S/A/D + 鼠标转向）
6. **下料单**：钢丝按直径分档、焊点数（每杆两端）、布料三角网格面积、灯带米数、总功率、估算总重、运输超限判定；支持打印/PDF 与 TXT 导出

## 透光物理口径（与手算对齐）

```
灯珠光通量  Φ = 功率W × 发光效率lm/W
发光强度    I = Φ / 4π            （各向同性，cd）
内表面照度  E = I / d² × |cosθ| × 10⁶   （d 单位 mm，结果 lx）
有效透光率  τ_eff = τ × (1 − 0.85 × 颜料浓度)
透射照度    Eout = E × τ_eff
多灯/多灯珠：逐灯珠求和（无空间剔除，保证精确）
散射：邻接顶点按 scatter 系数一次混合，仅影响显示，不改变 raw 手算值
```

- `bakeSegment` 同时输出 `raw`（散射前，手算口径）与 `scattered`（散射+环境漏光，显示口径）
- 显示映射：`lux / 100lx × 曝光` 经 ACES 色调压缩，配合灯珠色温的黑体 RGB
- 性能：3.8 万三角面、约 200 灯珠全量烘焙约 90~100ms；杆件/节点用 InstancedMesh，照度烘焙到顶点色，场景内不堆实时点光源，旋转查看稳定流畅

## 工程结构

```
src/core    领域模型、IndexedDB、透光/力学/均匀性/下料/放样纯算法（无 three 依赖）
src/three   场景基座、InstancedMesh 构建、3D 编辑器
src/pages   六个页面
src/samples 龙/荷花/人物测试灯组生成器
scripts     手算校验与性能测试（node 原生 TS 执行）
```

## 已知简化

- 挠度按两端简支梁均布自重粗算，未计风载与多点支撑
- 遮挡不做阴影射线（灯在布内、骨架遮挡量级小），如需可在烘焙循环加 occluder
- 下垂为余弦位移模型，非布料物理仿真
